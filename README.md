# 개인 맞춤형 하루 칼로리 & 탄단지 계산기

## 프로젝트명 · 소개

**개인 맞춤형 하루 칼로리 & 탄단지 계산기**는 키·몸무게·나이와 활동량을 바탕으로 하루 섭취 칼로리와 탄수화물·단백질·지방 목표를 계산하는 파이썬 웹앱입니다. 인바디의 골격근량과 체지방량을 추가로 입력하면 더 개인화된 결과를 제공합니다.

사용자는 **살 빼기용**, **체중 유지용**, **벌크업용** 세 가지 식단 목표를 한 번에 비교할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 필수 정보 입력 | 키, 몸무게, 나이, 활동량을 입력합니다. |
| 선택 정보 입력 | 성별, 골격근량, 체지방량을 입력하면 결과의 정확도가 높아집니다. |
| 인바디 반영 계산 | 체지방량이 있으면 제지방량 기반 기초대사량(BMR)을 계산합니다. |
| 목표별 식단 제안 | 감량·유지·벌크업에 맞는 하루 칼로리와 탄단지를 제공합니다. |
| 입력-처리-출력 안내 | 앱 안에서 계산이 이루어지는 과정을 확인할 수 있습니다. |

| 구분 | 사용 기술 |
| --- | --- |
| 언어 | Python 3.10 이상 |
| 웹 프레임워크 | Streamlit |

```text
calorie_macro_calculator/
├── app.py               # Streamlit 웹앱 및 계산 로직
├── requirements.txt     # 필요한 파이썬 패키지
└── README.md            # 프로젝트 설명서
```

## 설치 · 실행 방법

```bash
# 1. 프로젝트 폴더로 이동
cd calorie_macro_calculator

# 2. 가상환경 생성 및 활성화 (선택)
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate

# 3. 필요한 패키지 설치
pip install -r requirements.txt

# 4. 웹앱 실행
streamlit run app.py
```

브라우저에서 표시되는 주소(보통 `http://localhost:8501`)를 열면 됩니다.

## 결과

입력을 완료하면 아래와 같은 세 가지 하루 섭취 목표가 화면에 표시됩니다.

| 목표 | 칼로리 기준 | 제공 결과 |
| --- | --- | --- |
| 살 빼기용 | 유지 칼로리의 80% | 하루 목표 칼로리, 탄수화물, 단백질, 지방 |
| 체중 유지용 | 유지 칼로리의 100% | 하루 목표 칼로리, 탄수화물, 단백질, 지방 |
| 벌크업용 | 유지 칼로리의 112% | 하루 목표 칼로리, 탄수화물, 단백질, 지방 |

체지방량을 입력한 경우에는 제지방량 기반 Katch-McArdle 식을, 입력하지 않은 경우에는 Mifflin-St Jeor 식을 활용해 기초대사량을 계산합니다. 단백질은 목표와 체성분 정보에 따라 체중 또는 제지방량 1kg당 약 1.6~2.15g을 반영하며, 지방은 목표 칼로리의 25%, 탄수화물은 남은 열량을 기준으로 계산합니다.

> 이 앱의 결과는 일반적인 추정치이며 의료 또는 영양 처방을 대신하지 않습니다.
